# RF7. El sistema debe permitir configurar precios y descuentos de los cursos

## Descripción

El sistema debe permitir al usuario autorizado establecer y modificar el precio de un curso y los descuentos aplicables. Los valores deben validarse antes de guardarse y reflejarse en la información del curso.

## Historia de usuario

**Como** usuario autorizado para administrar cursos,
**Quiero** configurar los precios y descuentos de un curso,
**Para** mantener actualizada su información comercial.

## Criterios de aceptación

- [ ] El sistema permite consultar el precio y los descuentos configurados.
- [ ] El sistema permite establecer o modificar el precio del curso.
- [ ] El sistema permite establecer o modificar los descuentos aplicables.
- [ ] El sistema valida que los valores ingresados sean válidos.
- [ ] Si existe un error de validación, el sistema informa el problema y no guarda el cambio.
- [ ] El sistema guarda correctamente los precios y descuentos.
- [ ] El sistema confirma cuando la información se actualiza.
