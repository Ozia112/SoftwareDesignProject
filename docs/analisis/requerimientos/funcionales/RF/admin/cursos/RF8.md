# RF8. El sistema debe permitir modificar la descripción de los cursos

## Descripción

El sistema debe permitir al usuario autorizado modificar la descripción de un curso. Antes de guardar los cambios, el sistema debe validar que la información cumpla con los criterios establecidos. (por determinar)

## Historia de usuario

**Como** usuario autorizado para administrar cursos,
**Quiero** modificar la descripción de un curso,
**Para** mantener actualizada la información que se muestra a las personas interesadas.

## Criterios de aceptación

- [ ] El sistema permite consultar la descripción actual del curso.
- [ ] El sistema permite editar la descripción del curso.
- [ ] El sistema valida que la descripción cumpla con los criterios establecidos.
- [ ] Si existe un error de validación, el sistema informa el problema y no guarda el cambio.
- [ ] El sistema guarda la descripción actualizada correctamente.
- [ ] El sistema confirma cuando la descripción se modifica.
- [ ] La descripción actualizada se muestra en la información del curso.
