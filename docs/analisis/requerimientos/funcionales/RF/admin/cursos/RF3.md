# RF3. El sistema debe permitir configurar los cupos de los cursos

## Descripción

El sistema debe permitir al usuario autorizado establecer y modificar la cantidad de cupos disponibles para un curso. El sistema debe validar que la cantidad ingresada sea válida antes de guardar el cambio.

## Historia de usuario

**Como** usuario autorizado para administrar cursos,
**Quiero** configurar los cupos de un curso,
**Para** controlar la cantidad de personas que pueden participar.

## Criterios de aceptación

- [ ] El sistema permite consultar los cupos configurados para un curso.
- [ ] El sistema permite establecer la cantidad de cupos disponibles.
- [ ] El sistema valida que la cantidad de cupos sea válida.
- [ ] Si la información es inválida, el sistema informa el error y no guarda el cambio.
- [ ] El sistema guarda la configuración de cupos correctamente.
- [ ] El sistema confirma cuando la configuración se actualiza.
- [ ] Los cupos actualizados se muestran en la información del curso.
