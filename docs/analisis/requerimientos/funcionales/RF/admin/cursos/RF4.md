# RF4. El sistema debe permitir configurar las fechas y horarios de los cursos

## Descripción

El sistema debe permitir al usuario autorizado establecer y modificar las fechas y horarios asociados a un curso. Antes de guardar la configuración, el sistema debe validar que la información sea completa y consistente.

## Historia de usuario

**Como** usuario autorizado para administrar cursos,
**Quiero** configurar las fechas y horarios de un curso,
**Para** informar cuándo se llevará a cabo y organizar su disponibilidad.

## Criterios de aceptación

- [ ] El sistema permite consultar las fechas y horarios configurados.
- [ ] El sistema permite registrar las fechas de inicio y finalización del curso.
- [ ] El sistema permite registrar uno o más horarios para el curso.
- [ ] El sistema valida que las fechas y horarios sean válidos.
- [ ] Si la información es inválida, el sistema informa el error y no guarda el cambio.
- [ ] El sistema guarda la configuración correctamente.
- [ ] El sistema confirma cuando las fechas y horarios se actualizan.
