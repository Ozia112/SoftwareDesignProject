# RF5. El sistema debe mostrar la numeralia de clientes por etapa

## Descripción

El sistema debe permitir al usuario autorizado consultar la cantidad de clientes clasificados en cada etapa asociada a un curso. La información debe mostrarse de forma clara y corresponder a los datos registrados en el sistema.

## Historia de usuario

**Como** usuario autorizado para administrar cursos,
**Quiero** consultar la cantidad de clientes por etapa,
**Para** conocer el estado de los clientes relacionados con cada curso.

## Criterios de aceptación

- [ ] El sistema permite seleccionar un curso para consultar su numeralia.
- [ ] El sistema muestra las etapas disponibles para el curso.
- [ ] El sistema muestra la cantidad de clientes correspondiente a cada etapa. (no sé si dejarla?)
- [ ] La información mostrada corresponde a los datos registrados en el sistema.
- [ ] El sistema informa cuando no existen clientes registrados en una etapa.
- [ ] El sistema permite actualizar la consulta para mostrar la información vigente.
