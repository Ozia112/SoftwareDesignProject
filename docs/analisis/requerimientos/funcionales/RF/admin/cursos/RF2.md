# RF2. El sistema debe permitir activar y desactivar cursos

## Descripción

El sistema debe permitir al usuario autorizado cambiar el estado de un curso entre activo e inactivo. El cambio debe validarse, guardarse correctamente y reflejarse en el catálogo de cursos.

## Historia de usuario

**Como** usuario autorizado para administrar cursos,
**Quiero** activar o desactivar un curso,
**Para** controlar los cursos que se encuentran disponibles.

## Criterios de aceptación

- [ ] El sistema permite consultar el estado actual de un curso.
- [ ] El sistema permite activar un curso inactivo.
- [ ] El sistema permite desactivar un curso activo.
- [ ] El sistema solicita confirmación antes de cambiar el estado.
- [ ] El sistema guarda el nuevo estado del curso.
- [ ] El sistema informa cuando el cambio se realiza correctamente.
- [ ] El estado actualizado se refleja en el catálogo de cursos.
