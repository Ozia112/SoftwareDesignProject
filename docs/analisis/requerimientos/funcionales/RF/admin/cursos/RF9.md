# RF9. El sistema debe permitir abrir cupos extemporáneos

## Descripción

El sistema debe permitir al usuario autorizado habilitar cupos extemporáneos para un curso cuando sea necesario. La configuración debe indicar la cantidad de cupos y las condiciones o periodo de disponibilidad correspondientes.

## Historia de usuario

**Como** usuario autorizado para administrar cursos,
**Quiero** abrir cupos extemporáneos para un curso,
**Para** permitir nuevas inscripciones fuera del periodo ordinario.

## Criterios de aceptación

- [ ] El sistema permite seleccionar un curso para abrir cupos extemporáneos.
- [ ] El sistema permite indicar la cantidad de cupos que se habilitarán.
- [ ] El sistema permite indicar el periodo o las condiciones de disponibilidad.
- [ ] El sistema valida que la configuración sea completa y válida.
- [ ] Si existe un error de validación, el sistema informa el problema y no habilita los cupos.
- [ ] El sistema registra y habilita los cupos extemporáneos correctamente.
- [ ] El sistema confirma cuando los cupos quedan disponibles.
