# RF6. El sistema debe permitir visualizar la lista de espera de los cursos

## Descripción

El sistema debe permitir al usuario autorizado consultar la lista de espera asociada a un curso. La información debe mostrarse de forma ordenada y corresponder a los registros existentes.

## Historia de usuario

**Como** usuario autorizado para administrar cursos,
**Quiero** visualizar la lista de espera de un curso,
**Para** conocer las personas que están esperando disponibilidad.

## Criterios de aceptación

- [ ] El sistema permite seleccionar un curso para consultar su lista de espera.
- [ ] El sistema muestra las personas registradas en la lista de espera.
- [ ] El sistema muestra la posición o el orden de cada registro.
- [ ] La información mostrada corresponde a los datos registrados en el sistema.
- [ ] El sistema informa cuando la lista de espera está vacía.
- [ ] El usuario autorizado puede actualizar la consulta para mostrar la información vigente.
