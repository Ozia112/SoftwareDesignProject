# RF1. El sistema debe permitir visualizar las conversaciones activas

## Descripción

El sistema debe permitir al usuario autorizado consultar las conversaciones activas asociadas a los clientes. La información debe mostrarse de forma clara y corresponder a las conversaciones que se encuentren en curso.

## Historia de usuario

**Como** usuario autorizado para administrar clientes,
**Quiero** visualizar las conversaciones activas,
**Para** consultar y dar seguimiento a las interacciones en curso.

## Criterios de aceptación

- [ ] El sistema permite acceder al listado de conversaciones activas.
- [ ] El sistema muestra las conversaciones que se encuentran en curso.
- [ ] El sistema muestra la información necesaria para identificar cada conversación.
- [ ] La información mostrada corresponde a los datos registrados en el sistema.
- [ ] El sistema informa cuando no existen conversaciones activas.
- [ ] El usuario autorizado puede actualizar el listado para consultar la información vigente.
