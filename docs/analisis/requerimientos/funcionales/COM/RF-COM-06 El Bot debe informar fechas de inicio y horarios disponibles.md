# RF-COM-06. El Bot debe informar fechas de inicio y horarios disponibles

## Descripción

El Bot debe proporcionar las fechas de inicio programadas y los horarios disponibles para cada evento cuando el Cliente potencial lo solicite.
La información se obtiene del Banco de contexto de evento.

## Historia de usuario

*Como* Cliente potencial interesado en inscribirme en un evento
*Quiero* conocer las fechas de inicio y horarios disponibles
*Para* organizar mi tiempo y confirmar mi disponibilidad

## Criterios de aceptación

- [ ] El Cliente potencial puede preguntar por próximas fechas o en el contexto adecuado el Bot las debe dar (el Cliente potencial pide información específica del evento sin mencionar directamente que quiere las fechas).
- [ ] El Bot responde con fechas actualizadas obtenidas del Banco de contexto de evento.
- [ ] Se muestran horarios organizados por jornada (mañana, tarde, noche, etc.).
