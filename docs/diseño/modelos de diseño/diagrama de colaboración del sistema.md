# Diagrama de Colaboración (UML)

Los diagramas de colaboración son una herramienta visual utilizada para modelar y representar la interacción estructural entre los distintos componentes de un sistema, mostrando cómo se comunican entre sí mediante el intercambio de mensajes numerados.

En el caso de nuestro sistema, se implementó un diagrama de colaboración para representar los siguientes procesos:

Proceso de consentimiento de privacidad de la persona interesada.
Proceso de calificación automática del cliente potencial (lead).
Proceso de validación de cupo, reserva temporal y confirmación de inscripción.
Proceso de gestión de lista de espera, notificaciones y cancelaciones.
