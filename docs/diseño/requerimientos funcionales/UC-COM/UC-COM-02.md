# UC-COM-02-01: Calificación automática de cliente potencial

## Actor principal
Persona interesada

## Actores secundarios
Sistema

## Descripción
El sistema evalúa automáticamente a una persona interesada durante su interacción con el agente conversacional para determinar su nivel de interés y asignar una calificación.

## Flujo principal

1. La persona interesada inicia conversación con el agente conversacional.
2. El agente realiza preguntas sobre interés, presupuesto, disponibilidad y urgencia.
3. La persona responde las preguntas.
4. El sistema analiza las respuestas utilizando reglas de evaluación.
5. El sistema asigna una calificación al cliente potencial.

## Flujo alterno

### Información incompleta
1. La persona no responde todas las preguntas.
2. El sistema solicita información adicional.

## Postcondiciones

- El cliente potencial queda registrado con una calificación en el sistema.
